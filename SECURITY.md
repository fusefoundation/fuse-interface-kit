# Security policy

This repository contains the FUSE Interface Kit and its integration examples. The official project website is [fuseprotocol.org](https://fuseprotocol.org/).

If you find a potential security issue, please do not post the details in a public issue or pull request. Use **Report a vulnerability** under this repository's Security tab if it is available. Otherwise contact [FUSE support](mailto:support@fuseprotocol.org) privately and mention the repository and affected version or commit. For suspected issues in the live protocol rather than this kit, use FUSE support.

Include the affected component, observed impact, and enough non-sensitive context to investigate. Do not include seed phrases, private keys, signed payloads, or personal information. Do not use real funds or other people's accounts to demonstrate an issue.
